# 📚 Open Library Book Data Extractor

A simple Python project that retrieves book information from the [Open Library API](https://openlibrary.org/developers/api), filters books by publication year, and exports the results to a CSV file.

## ✨ Features

- Fetch book data from the Open Library Search API
- Retrieve up to 50 search results for Python-related books
- Filter books published after the year 2000
- Export book titles and publication years to a CSV file
- Create an Excel-friendly CSV file with UTF-8 encoding

## 🛠️ Technologies

- **Python**
- **Requests** — for sending HTTP requests
- **CSV** — for exporting data
- **Open Library API** — as the data source
